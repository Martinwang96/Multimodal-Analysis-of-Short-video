《反方向的钟》
多模态叙事分析

微短剧具有时长短、节奏快、反转强、情绪密度高的传播特征，适合从文本、情感与叙事结构的角度做计算分析。 本项目构建了一条"转写 — 事件检测 — 情感分析 — 可视化"的研究型管线：先用 FunASR 完成中文转写与说话人分离， 再以 BERTopic + 相似度模型 + 规则系统划分事件边界，随后进行句子 / 事件 / 说话人三级情感分析， 最终服务于短剧叙事节奏与情绪转折的解释。

01

研究背景与目标

本研究以中文微短剧《反方向的钟》（88 集）为分析对象。短剧的单集时长极短、对白高度密集， 情绪随事件快速切换，传统的逐集人工细读难以量化其叙事策略，因此需要一条自动化的计算分析流程。

分析所用的全部对白文本由 FunASR 自动转写产出，并经人工逐句校对台词与说话人归属后进入后续分析， 以保证事件划分与情感计算的输入质量。

  • 将短剧音视频转写为结构化对白数据（说话人 / 文本 / 集）
  • 识别事件边界，获得比"集"更细粒度的叙事单元
  • 计算句子级、事件级、说话人级情感得分
  • 可视化角色与事件间的情感波动，定位情绪转折点
  • 为叙事节奏、反转结构与多模态个案分析提供数据支持
02

方法管线

1
音视频转写与说话人分离 前置步骤 · 脚本未公开

基于 FunASR 调用 ASR、VAD、标点恢复与说话人分离模型（ffmpeg 预处理为 16k 单声道）， 输出逐句转写 CSV。对应 app_design_update.py / download_model.py， 该部分代码未随仓库公开，本页数据从其转写结果开始。

2
人工校对 人工环节

自动转写后的全部台词与说话人结果均经人工校对，整理为含 说话人 / 文本内容 / source（集） 的结构化 CSV。

3
文本基础分析 本页可交互

jieba 分词后的词频统计、词云、角色台词数量与字数分布。对应 01_文本分析_basis.ipynb， 见文本分析页。

4
事件检测 本页可交互

混合式方法：Erlangshen-Ubert-330M 嵌入 + BERTopic 标记初始边界， Erlangshen-Roberta-110M-Similarity 计算相邻单元相似度， 再经优先级规则（同说话人合并 / source 切换 / 中文复句关联词）细化，共识别 375 个事件。 对应 02_events_process_v5.py，见事件检测页。

5
情感分析 本页为词典近似实现

原项目使用 Erlangshen-Roberta-110M-Sentiment 输出句子 / 事件 / 说话人三级得分 （对应 03_sentiment_analysis_v3.py，结果文件未随仓库公开）。 本页采用内置中文情感词典的轻量打分复现其分析思路：趋势走向可参考，绝对数值与模型结果存在差异。 见情感分析页。

6
可视化与对白浏览 本页可交互

原项目的 matplotlib 静态图（04_visualization.py）在本页重构为 ECharts 交互图表； 对话浏览页支持按事件 / 集 / 说话人 / 关键词检索全部对白。

7
OpenFace 面部表情分析 仅 PPT 展示 · 未纳入仓库

项目展示材料中还包含基于 OpenFace 的面部 Action Unit 分析（如以 AU06 + AU12 组合识别"高兴"）， 用于将文本情感与视觉表情共同解释叙事策略；对应代码未公开，本页不含该部分结果。

04

数据说明与局限

数据起点
本页全部分析基于事件检测结果文件 02_result_反方向的钟.csv（2916 条对白，含 BERTopic 主题 ID 与事件 ID）。音视频转写为前置离线完成，转写脚本（FunASR GUI）未随仓库公开。
人工校对边界
自动转写产出的台词与说话人归属经过人工逐句校对，再进入事件检测。这是研究上合理的做法，也意味着本流程的非全自动环节在此。
情感分析差异
原项目的情感结果（sentiment_results/，Erlangshen 模型产出）未随仓库公开。本页情感页为内置中文情感词典的轻量实现，仅用于复现分析方法与交互展示，趋势可参考，绝对数值与模型结果存在差异。
未纳入部分
OpenFace 面部表情（Action Unit）分析仅在项目 PPT 中展示，处理脚本未公开；词云图片等静态产物亦未随仓库提供，本页词云由 jieba 分词实时计算生成。
